Timing pipeline (per frame)

1
Sample AudioContext.currentTime via GameClock.now().
The only monotonic clock trusted for judging. Zero-based, pause-aware. Never performance.now() for judging, never CSS animation progress.
2
GameEngine.update(now) resolves auto-miss and fires onEventActive.
Pure state machine. Events are precomputed from orbital periods, so the loop only matches, never simulates physics.
3
On input: capture audio.currentTime, convert to game time, subtract user latency offset, compare to nearest event.
Latency offset is a single user-adjustable value; calibration measures the combined round-trip offset against a metronome.
4
Schedule audio at absolute AudioContext.currentTime with a small lookahead.
Sample-accurate, frame-rate independent. Skipped entirely in mute or visual-only mode.
5
Draw the solar system to Canvas from refs (no React re-render per frame).
HUD updates through React state but throttled to ~12 fps to avoid re-render churn.

Determinism: generateEvents(stage) solves the orbital-crossing equation in closed form, so the same stage config always yields the same event list. The PRNG (mulberry32) is seeded for any randomized fixtures. The test suite asserts seed reproducibility and a full end-to-end happy path against a synthetic clock.
